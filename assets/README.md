# Assets

Drop your demo media here. The main `README.md` references these paths — replace the
filenames below to match, or keep them and your files will render automatically.

## `screenshots/`

Referenced in the README:

| File | Suggested content |
|------|-------------------|
| `video-compare.png` | Side-by-side comparison with per-move scores |
| `dashboard.png` | User dashboard with style progress |
| `courses.png` | Course creator form |
| `comparison-history.png` | Past comparisons, best score, and filters |
| `video-compare-regions.png` | Second comparison with torso / shoulder filters |

Tips: capture at a consistent width (~1600px), crop browser chrome, and keep each
under ~500 KB (PNG or JPEG).

## `demo/`

| File | Notes |
|------|-------|
| `demo.mp4` | ~29s, with audio: dashboard, then two comparisons. Embedded in the README. |
| `demo.gif` | Silent loop of the same cut. GIF cannot carry audio. |
| `comparison.mp4` | First side-by-side comparison, with audio |
| `comparison-regions.mp4` | Second comparison, with torso / shoulder filters and audio |

A GIF under ~10 MB inlines nicely on GitHub. For longer clips, commit an `.mp4`
and use a `<video>` tag in the README instead.

## Adding a link to an external demo video

If you host a longer walkthrough on YouTube/Loom, add a badge or button in the README
near the top, e.g.:

```markdown
[![Watch the walkthrough](https://img.shields.io/badge/▶_Watch-Walkthrough-red?style=for-the-badge)](https://your-link)
```
